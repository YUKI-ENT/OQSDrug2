# サマリー用薬剤名の整形

`DrugSummaryName.Format` で規格・剤形・引用符内のメーカー名を取り除き、既定ではカタカナを半角にする。一般名への置換は行わない。

| 元名称 | サマリー用名称 |
|---|---|
| ビラノアOD錠20mg | ﾋﾞﾗﾉｱ |
| スルピリド錠５０ｍｇ「アメル」 | ｽﾙﾋﾟﾘﾄﾞ |
| カロナール錠２００ ２００ｍｇ | ｶﾛﾅｰﾙ |
| レルベア200エリプタ30吸入用 | ﾚﾙﾍﾞｱ |
| ビタミンB12 | ﾋﾞﾀﾐﾝB12 |
| 五苓散 | 五苓散 |

通常のカタカナを残す場合は `Format(name, halfWidthKatakana: false)` を使う。現時点では画面の切替項目は設けず、LLM向けのサマリー用名称には半角を使用する。

LLMペイロードには元の `drugn` と整形済み `drugn_summary` の両方を入れる。プロンプトに、判断には元名称、出力にはサマリー用名称を使う指示を追加する。元の薬歴・薬剤コード・薬剤の集約キー・日数の計算は変更しない。保存済みテンプレート本文も書き換えない。

加工対象は規則で識別できる表記に限定する。名前の一部である数字を一律削除せず、五苓散などの末尾の「散」も無条件では削除しない。未知の剤形・メーカーの表記は残ることがあるため、追加例に基づいて規則を拡張する。

`tests/Run-DrugSummaryNameTests.ps1` で全半角、濁点、メーカー、規格、吸入器表記、残すべき名称、繰り返し変換しても結果が変わらないことを検証する。
